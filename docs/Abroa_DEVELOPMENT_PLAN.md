## 阶段推进
每任务读相关指南 -> 写失败用例 -> 实现 -> 针对性测试 -> 回归 -> 更新实施矩阵 -> 小提交。不得把 mock 第三方结果当真连接。P0 若环境未经授权，记录不能运行的步骤；不能绕过 AGENTS 禁止自动迁移、启动 rails server 等限制。任务被阻塞时继续独立无阻塞项；只有外部凭证、样例或关键产品范围确实不明才向用户询问。禁止自行确定收费价格。P6 是后端功能、回归、权限、Docker 实际验证门槛；未通过不得启动新前端。公开成本数据库、多人账本、匿名统计均后续，不建本阶段空壳。
